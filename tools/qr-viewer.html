RollingDoor QR code

Reads the pairing QR code from your board over USB. Nothing leaves this computer.

  1. Flash the firmware and plug the board into this computer with a USB cable.
  2. Close any serial monitor that is using the port.
  3. Click Connect and pick the board (USB JTAG/serial debug unit).

RollingDoor pairing code. Keep it private.

Anyone with this code can pair a phone while pairing is open. Keep it somewhere safe, not on the box by the door, and never commit it.

No Web Serial? Paste the serial output instead

Web Serial works in Chrome and Edge. In other browsers, run pio device monitor, type qr, and paste everything it prints here.
